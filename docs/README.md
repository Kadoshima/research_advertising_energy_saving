# docs 運用ルール

- 更新日: 2026-01-14
- 目的: docs配下の配置と記述ルールを固定し、無秩序な増殖を防ぐ

## 配置ルール

- Phase固有ドキュメントは `docs/フェーズN/<task_slug>/` に置く
- フェーズは合意なく新設しない（既存フェーズのみ使用）
- `<task_slug>` は日本語可。ローマ字化する場合は lowercase snake_case
- 作業ディレクトリには必ず `README.md` を置き、用途と生成物を記載する
- 参照ファイル（コード/データ/結果/設定）はREADMEに明示し、パスを固定する
- 図表や表などの出力物は参照文書と同じディレクトリに置く

## README 必須項目

- 目的と範囲
- 入力データ（出所、バージョン、SHA256、行数）
- 出力物（ファイル名、生成日、生成スクリプト）
- 再現手順（コマンド）
- 指標（単位付き、出典付き）
- 状態（draft/frozen/obsolete）
- 関連リンク（他フェーズや根拠文書）
- 更新履歴（YYYY-MM-DD）

## 運用ルール

- 重要な作業は worklog に追記する（JST、同日同ファイル）
- 重要な判断理由は decision_log に残す

## 索引

- フェーズ1: `docs/フェーズ1/README.md`
- フェーズ2: `docs/フェーズ2/README.md`
- アーカイブ: `docs/_archive/README.md`
