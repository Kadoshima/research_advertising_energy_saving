## 1-3. Phase 2 MVP実装（Safe-UCBオフライン評価）

### 目的
Safe Contextual Banditが「制約を守りつつ報酬改善」することを図で示す。

### モデル定義（固定）

| 要素 | 定義 | 値 |
|------|------|-----|
| コンテキスト | x | CCS ∈ [0,1]（1次元）|
| 行動集合 | A | {500, 1000, 2000} ms |
| 報酬 | r(a) | -μC(a)（負のエネルギー、最大化）|
| 制約 | g(x,a) | Pout(τ|x,a) ≤ ε |
| τ | 許容遅延 | 1.0 s（固定）|
| ε | 制約閾値 | 0.10（10%）|

### 比較対象（4つ）

| 手法 | 説明 |
|------|------|
| **Safe-UCB** | 提案手法。制約を守りながら探索 |
| **UCB** | 制約なし。報酬のみ最大化 |
| **Fixed-CCS** | Phase 1の閾値写像。学習なし |
| **Oracle** | 真の最適行動。上界 |

### 出力する図（4枚）

1. **累積Regret推移**: Oracle比での累積損失
2. **制約違反率推移**: violations / T
3. **平均エネルギー推移**: 各手法のμC(a)
4. **Warm-start vs Cold-start**: 初期化による収束速度差
