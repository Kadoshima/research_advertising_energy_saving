## 1. 問題設定

### 1.1 最適化問題

```
minimize   E[μC(a)]           # エネルギー最小化（報酬最大化は -μC）
subject to Pout(τ | a) ≤ ε    # QoS制約
where      a = π(x)           # 方策：コンテキストから行動を選択
```

### 1.2 構成要素

| 要素 | 記号 | 定義 | MVP値 |
|------|------|------|-------|
| **コンテキスト** | x | CCS（複合信頼度スコア） | x ∈ [0, 1] |
| **行動集合** | A | 広告間隔 | {500, 1000, 2000} ms |
| **報酬** | r(a) | -μC(a) | 負のエネルギー |
| **制約** | g(a) | Pout(τ \| a) | τ = 1.0 s |
| **制約閾値** | ε | 許容違反率 | 0.10 (10%) |

### 1.3 なぜ CCS を使うか（(U,S)ではなく）

1. **Phase 1との一貫性**: Phase 1でCCS→T_adv写像を使用
2. **可視化の容易さ**: 1次元なので図が描きやすい
3. **十分性**: D4/D4Bで(U,S)分解の効果は既に示した

## 2. アルゴリズム

### 2.1 Safe-UCB（提案手法）

```python
def safe_ucb(x, t, models, epsilon):
    """
    Safe-UCB行動選択

    Args:
        x: コンテキスト（CCS値）
        t: 現在のステップ
        models: 報酬・制約モデル
        epsilon: 制約閾値

    Returns:
        a: 選択された行動
    """
    # 1. 各行動の報酬UCB計算
    ucb_values = {}
    for a in A:
        mu_r = models.reward.mean(a)
        sigma_r = models.reward.std(a)
        ucb_values[a] = mu_r + sqrt(2 * log(t) / n(a)) * sigma_r

    # 2. 安全行動集合の計算
    safe_set = []
    for a in A:
        pout_estimate = models.constraint.predict(a)
        pout_ucb = pout_estimate + models.constraint.confidence(a)
        if pout_ucb <= epsilon:
            safe_set.append(a)

    # 3. フォールバック（安全集合が空の場合）
    if len(safe_set) == 0:
        safe_set = [min(A)]  # 最も保守的な行動（500ms）

    # 4. 安全集合内でUCB最大の行動を選択
    a_star = argmax(a in safe_set, ucb_values[a])

    return a_star
```

### 2.2 比較手法

#### UCB（制約なし）

```python
def ucb(x, t, models):
    """制約を無視してUCB最大の行動を選択"""
    ucb_values = {}
    for a in A:
        mu_r = models.reward.mean(a)
        sigma_r = models.reward.std(a)
        ucb_values[a] = mu_r + sqrt(2 * log(t) / n(a)) * sigma_r

    return argmax(a in A, ucb_values[a])
```

#### Fixed-CCS（Phase 1写像）

```python
def fixed_ccs(x, thresholds):
    """Phase 1の閾値写像（学習なし）"""
    theta_high, theta_low = thresholds  # 0.90, 0.80

    if x >= theta_high:
        return 2000  # 省電力優先
    elif x >= theta_low:
        return 1000  # 中間（500msがないので1000ms）
    else:
        return 500   # QoS優先
```

#### Oracle（上界）

```python
def oracle(x, true_rewards, true_constraints, epsilon):
    """真の報酬・制約を知っている場合の最適行動"""
    feasible = [a for a in A if true_constraints[a] <= epsilon]
    if len(feasible) == 0:
        return min(A)
    return argmax(a in feasible, true_rewards[a])
```

## 3. モデル定義

### 3.1 報酬モデル（μC推定）

**入力**: 行動 a
**出力**: μC(a) の平均・分散

**データソース**: `deltae_v02`（ΔE基準データ）

**実装**:
```python
class RewardModel:
    def __init__(self, data_path):
        # ΔE基準データから各行動のμCを計算
        self.mu = {}  # a -> mean μC
        self.sigma = {}  # a -> std μC
        self.n = {}  # a -> sample count

        for a in [500, 1000, 2000]:
            samples = load_delta_e(data_path, a)
            self.mu[a] = np.mean(samples)
            self.sigma[a] = np.std(samples)
            self.n[a] = len(samples)

    def mean(self, a):
        return self.mu[a]

    def std(self, a):
        return self.sigma[a]

    def sample(self, a):
        """報酬のサンプリング（シミュレーション用）"""
        return np.random.normal(self.mu[a], self.sigma[a])
```

### 3.2 制約モデル（Pout推定）

**入力**: 行動 a
**出力**: Pout(τ|a) の推定値・信頼区間

**データソース**: E1系（D1-D4B）+ E2系

**実装**:
```python
class ConstraintModel:
    def __init__(self, data_path, tau=1.0):
        self.tau = tau
        self.pout = {}  # a -> Pout estimate
        self.pout_std = {}  # a -> std
        self.n = {}

        for a in [500, 1000, 2000]:
            tl_samples = load_tl(data_path, a)
            violations = sum(1 for tl in tl_samples if tl > tau)
            self.pout[a] = violations / len(tl_samples)
            # Wilson score interval for binomial
            self.pout_std[a] = wilson_std(violations, len(tl_samples))
            self.n[a] = len(tl_samples)

    def predict(self, a):
        return self.pout[a]

    def confidence(self, a):
        """UCB用の信頼幅"""
        return 1.96 * self.pout_std[a]  # 95% CI

    def sample(self, a):
        """制約値のサンプリング（シミュレーション用）"""
        return np.random.binomial(1, self.pout[a])
```

### 4.2 評価指標

| 指標 | 定義 | 計算方法 |
|------|------|---------|
| **累積Regret** | Σ (r_oracle - r_t) | Oracle報酬との累積差 |
| **制約違反率** | Σ I[g_t > ε] / T | 違反ステップの割合 |
| **平均エネルギー** | Σ μC(a_t) / T | 選択行動の平均コスト |
| **収束速度** | Regret曲線の傾き | 後半100ステップの傾き |

### 4.3 成功基準（事前定義）

| 指標 | 基準 | 根拠 |
|------|------|------|
| 制約違反率 | ≤ ε (0.10) | 制約を守る |
| Regret順序 | UCB > Safe-UCB | Safe-UCBが制約を守りつつ改善 |
| Warm-start効果 | Cold比で収束が早い | Phase 1写像の有効性 |
