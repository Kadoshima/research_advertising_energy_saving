## 2. 残タスク一覧（優先度順）

### 2.1 【P0: 最優先】RX MFDパーサー問題の解決

#### 2.1.1 問題の詳細

**診断カウンタ（シリアルログより）**:
```
cbTotal   = 7992   ← スキャン動作中（パケット検出）
cbNoMfd   = 150    ← MFD無しで落ちた
cbMfdBad  = 7842   ← MFDパース失敗で落ちた（99%）
cbAddrMismatch = 0 ← アドレス不一致はなし
```

**根本原因候補**:
1. TXのMFD形式（"MFxxxx"）とRXのoffset探索（0/2）が不一致
2. 他デバイス（Apple等 4C00xxxx）のMFDが混入
3. ESP32 Arduino Core 3.x での `String` / `std::string` 互換性問題
4. バッファオーバーフローまたはヒープ枯渇（長時間動作時）

### 2.3 【P2】ΔE/adv 計算と検証

#### 2.3.1 計算式

```
ΔE/adv = (E_ON - E_OFF) / N_adv

E_ON  : ON計測の総エネルギー [mJ]
E_OFF : OFF計測の平均電力 P_off × ON計測時間 T_on [mJ]
N_adv : 広告回数（TXSD tick_countまたは期待値）
```

#### 2.4.2 PDR計算式

```

PDR_unique = unique_seq_count / expected_count
expected_count = trial_ms / adv_interval_ms

    rx_unique=540 → PDR_unique = 0.90
```
