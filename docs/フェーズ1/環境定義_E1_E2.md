# 実験環境定義書: E1/E2/E2+

- 作成日: 2026-01-21
- 文書ID: Phase1/ENV-DEF-2026-01-21
- 目的: BLE広告実験における干渉環境（E1/E2/E2+）を定量的に定義し、再現性を担保する

---

## 1. 環境分類の定義

### 1.1 定義表

| 環境ID | 名称 | Wi-Fi干渉レベル | 最強AP RSSI | 代表的なChannel Utilization | 用途 |
|--------|------|----------------|-------------|---------------------------|------|
| **E1** | 低干渉環境 | 弱 | ≤ -40 dBm | < 30% | 主結果、基準環境 |
| **E2** | 高干渉環境 | 中〜強 | -40 〜 -25 dBm | 30〜60% | 干渉耐性評価 |
| **E2+** | 極強干渉環境 | 極強 | > -25 dBm | > 60% | ストレステスト |

### 1.2 判定基準

環境分類は**最強APのRSSI**を主指標とする。Channel Utilizationは補助指標として記録する。

```
E1:  strongest_AP_RSSI ≤ -40 dBm
E2:  -40 dBm < strongest_AP_RSSI ≤ -25 dBm
E2+: strongest_AP_RSSI > -25 dBm
```

### 1.3 備考

- BLE（2.4 GHz）とWi-Fi（2.4 GHz）は同一周波数帯を共有するため、Wi-Fi干渉がBLE PDRに影響する
- E1は「通常のオフィス環境」、E2は「Wi-Fiルーター近接環境」、E2+は「AP直下・ストレス環境」を想定
- 干渉の定量化には**Wi-Fiアナライザアプリ**（例: Analiti, WiFi Analyzer）を使用

## 2. 計測方法

### 2.1 使用ツール

| ツール | 用途 | 記録項目 |
|--------|------|---------|
| **Analiti** (Android) | Wi-Fi環境計測 | RSSI, チャンネル, Channel Utilization |
| **WiFi Analyzer** (Android) | 代替ツール | RSSI, チャンネル分布 |

### 2.2 記録必須項目

実験実施時に以下を`manifest.csv`または`worklog`に記録する:

| 項目 | 単位 | 例 |
|------|------|-----|
| `env_id` | - | E1, E2, E2+ |
| `strongest_ap_rssi_dbm` | dBm | -20 |
| `strongest_ap_ssid` | - | MyRouter_2.4G |
| `wifi_channel` | - | 1 (2412 MHz) |
| `channel_width_mhz` | MHz | 20 |
| `channel_utilization_pct` | % | 45 |
| `other_ap_rssi_dbm` | dBm | -48 (CWN等) |
| `measurement_app` | - | Analiti v1.2.3 |
| `measurement_device` | - | Galaxy S9 (Android 10) |
| `measurement_time` | ISO8601 | 2026-01-21T15:30:00+09:00 |

### 2.3 計測タイミング

- **実験開始前**: 干渉環境を計測・記録
- **実験中**: 干渉源（動画再生等）を維持
- **実験終了後**: 必要に応じて再計測

    \toprule

### 4.2 本文記載例

> 実験環境は，Wi-Fi干渉レベルに基づき3段階に分類した（表\ref{tab:env_interference}）．
> E1（低干渉）は最強APのRSSIが$-40\,\si{\decibelmilliwatt}$以下の通常環境，
> E2（高干渉）は$-40$〜$-25\,\si{\decibelmilliwatt}$のルーター近接環境，
> E2+（極強干渉）は$-25\,\si{\decibelmilliwatt}$を超えるAP直下環境である．
> 主結果はE1で取得し，E2/E2+は干渉耐性の補足評価として扱う．
