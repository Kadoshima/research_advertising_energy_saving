# 修論 表現ルール（恒久）

## 文体/語彙
- 本文はである調を基本とし，口語/比喩/砕けた表現は学術語へ置換する。
- 「〜得る」は必要性が高くない限り「可能性がある」を優先する。
- 「一方」と「トレードオフ」などの重複は避け，構文を整理する。

## 研究目的・貢献の表現
- 「枠組みを扱う」は「枠組みを提案する/目的とする」など主体性を明示する表現に置換する。
- 「評価できるように整理する」は「計測システム/基盤を構築する」など行為を明確化する表現に置換する。
- 「省電力になりうる」は「省電力化が可能である」を優先する。
- 「基盤を与える」は「基盤を提供する/構築する」を優先する。

## 用語の定義/初出の説明
- scan70は初出で「scan dutyを70%に低下」など簡潔に説明する。
- 「短間隔予算」は初出で「短間隔の使用量（滞在量）」として補足する。
- U-shuffleは「時系列構造を乱す」表現で統一する。
- U-shuffleの見出しは「時系列シャッフル」を用いて具体的な操作を示す。
- Valley Areaは不感地帯（Blind Spot）に統一する。
- Outage解析は停止確率（Outage Probability）解析に統一する。
- Actorsはアクター（構成要素）に統一する。
- Safety Oracleは安全基準（Safety Oracle）に統一する。
- Capabilitiesはシステム要件（Capabilities）に統一する。
- 破綻モードは不具合要因（Failure Modes）に統一する。
- Golden Masterは基準構成（Reference Configuration）に統一する。
- 制約帯プロットは制約充足領域の可視化（Constraint Band Plot）に統一する。
- 動的切替（2値制御）は動的制御（2値切替）に統一する。

## 見出しの統一
- 疑問形や文学的表現は避け，名詞句で統一する。
  - 例: 「sleep制御の役割」「非理想スキャン環境」「MABによる広告間隔選択」「非学習型アプローチ」。

## 口語表現の置換例
- ボトルネック → 課題
- ねじれ → トレードオフ
- 決め打ち → 固定
- 揺らぐ → 変動する
- 寄せる → 選択する
- 張り付く → 固定される/収束する
- 閾値遊び → 閾値の偶発的一致
- 単位監査 → 単位整合の確認
- 間欠化 → 間欠実行
- 退避 → 移行
- 監査 → 整合性確認/妥当性確認
- 合格条件 → 妥当性判断基準
- 尾（遅延分布） → 裾（Tail）
- 直感に反する → 理論的予測と整合しない

## 既存用語の維持
- 制約帯など本文で広く使う語は，局所的な言い換えより一貫性を優先する。
- KPIを評価指標へ置換する場合は，全章で表記を統一する。
