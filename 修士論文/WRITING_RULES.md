# 修士論文 書式ルール（確定）

## 0. 前提
- 体裁は大学配布テンプレ（Word + master_thesis_cls.cls）に準拠する。
- 実装は `修士論文/chubuthesis.sty` を正とし、差分は明記して運用する。

## 1. レイアウト基準（大学配布テンプレ準拠）
- 用紙: A4
- 本文領域: 160mm x 232mm
- 余白: 左右 25mm
- ヘッダーなし、フッター右下ページ番号
- 本文フォント: 12pt、行送り 18pt

## 2. 文体・口調（研究室スタイル）
- 本文は **である調** に統一する。
- 謝辞のみ **ですます調** とする。
- 一人称は避け、「本研究」「本論文」「本章」「本節」を主語にする。
- 句読点は **「，」「．」** を使用する。
- 英数字は半角に統一する。
- 用語は本文内で統一する（例: BLEアドバタイジング）。
- 口語・評価語（例: OK, すごい, ちょっと, かも 等）は避け、学術表現に置換する。

## 3. 章構成（標準パターン）
- 前付け: 表紙 → 修士論文題目・論文要旨 → 目次（ローマ数字）
- 本文: 第1章〜（背景、提案、評価など）
- 後付け: 謝辞 → 参考文献（必要なら参考URL）→ 付録
- 各章の冒頭は「本章では，〜について述べる．」で導入する。
- 各節の冒頭は「本節では，〜について説明する．」で導入する。
- 「はじめに」は背景→課題→目的→構成案内の順で書く。

## 4. 図・表
- 図キャプションは **図の下**、表キャプションは **表の上** に配置する。
- 図表番号は **章.連番**（例: 図 2.1 / 表 4.1）で統一する。
  - 章-連番（図 2-1）へ切替える場合は `chubuthesis.sty` の番号定義を更新する。
- サブ図は (a)(b) 表記で区別する。
- 本文中では「図 2.1 に示す．」「表 4.1 から分かる．」の形式で参照する。
- 引用図はキャプション末尾に「([1]より引用)」を付す。

## 5. 数式
- 数式は「式(1)」形式で番号を付ける。
- 数式の直後に変数の意味を列挙して説明する。

## 6. 参考文献
- 文中引用は [1], [2] の番号表記に統一する。
- Web文献は URL とアクセス日を明記する。

## 7. 要旨
- 40字 x 30行、1ページ以内
- 「論文要旨」の下線は不要

## 8. 表紙・背表紙
- 表紙は外枠の太線を入れる。
- 年度表示は漢数字。
- 題目は枠内に収める（長い場合は改行）。
- 背表紙は縦書き、英字・元素記号は横向き。
