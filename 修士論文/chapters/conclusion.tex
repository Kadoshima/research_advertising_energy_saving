\chapter{おわりに}

本研究では，HARの推論不確実度に基づくBLEアドバタイジング間隔の適応制御を提案した．

\section{本研究の成果}

\begin{enumerate}
  \item \textbf{評価基盤の構築}：同一試行で電力とQoSを評価できる三ノード構成の計測系を構築した．
  
  \item \textbf{時間同期手法の確立}：定数オフセット補正により，TLと$P_{\mathrm{out}}$の正確な算出を実現した．
  
  \item \textbf{中間運用点の実証}：動的制御が，固定\SI{100}{\milli\second}と\SI{500}{\milli\second}の間の運用点として成立することを実機で示した．
  
  \item \textbf{頑健性の検証}：受信条件悪化時でも，提案手法はQoS制約を満たしつつ省電力を維持した．
  
  \item \textbf{役割分離の明確化}：$U$が電力を，CCSがQoSを改善する役割分担を示した．
  
  \item \textbf{高干渉環境での性能改善}：TailGuardにより，高干渉下でもQoS制約を満たす運用点を確認した．
  
  \item \textbf{Safe Contextual Banditへの接続}：シミュレーションにより，オンライン最適化への拡張可能性を示した．
\end{enumerate}

\section{今後の課題}

\begin{itemize}
  \item 行動空間の拡張（1000 ms，2000 msの追加）
  \item 実機でのSafe Contextual Bandit実装
  \item モデルの較正（温度スケーリング等）
  \item スキャン挙動の端末差の整理
\end{itemize}
